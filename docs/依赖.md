# 依赖

## 必选

| 项 | 版本 | 用途 |
| --- | --- | --- |
| C++ 编译器 | gcc 7+ 或 clang，C++17 | 核心库 |
| pthread | 系统 | 平台层链接 |
| CMake | 3.10+ | 可选，没有时用根目录 Makefile |

## 可选

| 开关 | 库 | 用途 |
| --- | --- | --- |
| `CP_WITH_OPENSSL=ON` | OpenSSL 1.1.1 或 3.x | 配对与 MFi 签名。找不到则跳过 |
| `CP_PLATFORM_LIBUSB=ON` | libusb-1.0 | 桌面 USB 探测 |
| `CP_UI_QT5=ON` | Qt5 Widgets | 设置窗口，不用 Qt6 |

不要引入 Electron、Node、NetworkManager、libsecret、FUSE。嵌入式平台用厂商蓝牙、SoftAP 和显示 API 实现 `platform` 接口。
